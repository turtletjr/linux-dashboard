Logos for the TV Remote widget's app buttons.

Drop one file per app in `TV_APPS` (see `main.py`), named after the app id:

    wholphin.svg   youtubetv.svg   appletv.svg     (.png, .webp and .jpg also work)

Use each app's own logo from its brand/press page. An app without a file just
shows its name. Keep them small and square-ish; the button shows them ~18px tall.
